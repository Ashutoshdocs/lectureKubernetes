================================================================================
                    KUSTOMIZE END-TO-END PRACTICAL
================================================================================

OBJECTIVE
================================================================================

Learn Kustomize by deploying the SAME application into multiple environments
(DEV and PROD) without modifying the original YAML files.

Kustomize is built into kubectl and allows you to customize Kubernetes
manifests using overlays.

Benefits:
- Reuse YAML files
- Change replica counts
- Change images
- Add namespaces
- Add labels
- Add annotations
- Generate ConfigMaps
- Generate Secrets
- Apply patches

================================================================================
INSTALLATION CHECK
================================================================================

kubectl version --client

kubectl kustomize --help

OR

kustomize version

================================================================================
PROJECT STRUCTURE
================================================================================

kustomize-demo/

├── base
│   ├── deployment.yaml
│   ├── service.yaml
│   └── kustomization.yaml
│
└── overlays
    ├── dev
    │   └── kustomization.yaml
    │
    └── prod
        └── kustomization.yaml

================================================================================
STEP 1 - CREATE DIRECTORY STRUCTURE
================================================================================

mkdir -p kustomize-demo/base
mkdir -p kustomize-demo/overlays/dev
mkdir -p kustomize-demo/overlays/prod

cd kustomize-demo

tree

================================================================================
STEP 2 - CREATE BASE DEPLOYMENT
================================================================================

File:
base/deployment.yaml

--------------------------------------------------------------------------------

apiVersion: apps/v1
kind: Deployment

metadata:
  name: student-app

spec:
  replicas: 2

  selector:
    matchLabels:
      app: student

  template:
    metadata:
      labels:
        app: student

    spec:
      containers:

      - name: nginx

        image: nginx

        ports:
        - containerPort: 80

--------------------------------------------------------------------------------

================================================================================
STEP 3 - CREATE BASE SERVICE
================================================================================

File:
base/service.yaml

--------------------------------------------------------------------------------

apiVersion: v1
kind: Service

metadata:
  name: student-service

spec:

  selector:
    app: student

  ports:
  - port: 80
    targetPort: 80

  type: NodePort

--------------------------------------------------------------------------------

================================================================================
STEP 4 - CREATE BASE KUSTOMIZATION
================================================================================

File:
base/kustomization.yaml

--------------------------------------------------------------------------------

resources:

- deployment.yaml

- service.yaml

--------------------------------------------------------------------------------

================================================================================
STEP 5 - VERIFY BASE
================================================================================

kubectl kustomize base

OR

kustomize build base

================================================================================
STEP 6 - CREATE DEV OVERLAY
================================================================================

File:
overlays/dev/kustomization.yaml

--------------------------------------------------------------------------------

resources:

- ../../base

namespace: dev

namePrefix: dev-

commonLabels:

  environment: development

replicas:

- name: student-app
  count: 1

--------------------------------------------------------------------------------

================================================================================
STEP 7 - CREATE DEV NAMESPACE
================================================================================

kubectl create namespace dev

================================================================================
STEP 8 - PREVIEW DEV OUTPUT
================================================================================

kubectl kustomize overlays/dev

OR

kustomize build overlays/dev

Observe:

Deployment Name:
dev-student-app

Namespace:
dev

Replica Count:
1

================================================================================
STEP 9 - DEPLOY DEV ENVIRONMENT
================================================================================

kubectl apply -k overlays/dev

================================================================================
STEP 10 - VERIFY DEV ENVIRONMENT
================================================================================

kubectl get all -n dev

kubectl get deployment -n dev

kubectl describe deployment dev-student-app -n dev

================================================================================
IMAGE OVERRIDE PRACTICAL
================================================================================

Requirement:

DEV  = nginx
PROD = nginx:latest

Edit:

overlays/prod/kustomization.yaml

--------------------------------------------------------------------------------

resources:

- ../../base

namespace: prod

images:

- name: nginx
  newTag: "1.25"

--------------------------------------------------------------------------------

Verify:

kubectl kustomize overlays/prod

Deploy:

kubectl apply -k overlays/prod

Verify:

kubectl get deployment -n prod -o yaml

================================================================================
CONFIGMAP GENERATOR PRACTICAL
================================================================================

Edit:

base/kustomization.yaml

--------------------------------------------------------------------------------

resources:

- deployment.yaml

- service.yaml

configMapGenerator:

- name: student-config

  literals:

  - course=DevOps

  - trainer=Ashutosh

--------------------------------------------------------------------------------

Deploy:

kubectl apply -k overlays/dev

Verify:

kubectl get configmap -n dev

Observe:

student-config-xxxxx

Hash generated automatically.

================================================================================
NAME PREFIX PRACTICAL
================================================================================

namePrefix: dev-

Result:

student-app

becomes

dev-student-app

================================================================================
NAME SUFFIX PRACTICAL
================================================================================

nameSuffix: -v1

Result:

student-app

becomes

student-app-v1

================================================================================
CHANGE NAMESPACE WITHOUT EDITING YAML
================================================================================

namespace: production

Deploy:

kubectl apply -k overlays/prod

Everything automatically deploys into production namespace.

================================================================================
PATCH PRACTICAL
================================================================================

Create:

overlays/prod/replica-patch.yaml

--------------------------------------------------------------------------------

apiVersion: apps/v1
kind: Deployment

metadata:
  name: student-app

spec:
  replicas: 10

--------------------------------------------------------------------------------

Update:

overlays/prod/kustomization.yaml

--------------------------------------------------------------------------------

resources:

- ../../base

patches:

- path: replica-patch.yaml

--------------------------------------------------------------------------------

Preview:

kubectl kustomize overlays/prod

Deploy:

kubectl apply -k overlays/prod

Verify:

kubectl get deployment -n prod
